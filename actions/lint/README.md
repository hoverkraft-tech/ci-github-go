## Overview

Check formatting, module metadata and golangci-lint v2 diagnostics. Run setup-go first. Reports are retained after failures; see docs/usage/README.md.

See the [usage guide](../../docs/usage/README.md).

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-go/actions/lint@c1b86fe6ecd03a1f106b6ecdae7a1f2857572c7b # main
  with:
    # Go module directory.
    # Default: `.`
    working-directory: .

    # Pinned golangci-lint v2 release.
    # Default: `v2.15.0`
    golangci-lint-version: v2.15.0

    # Trusted Bash command replacing the default formatting and lint checks. Project configuration remains authoritative.
    command: ""

    # Outer calling job ID for consolidated ci-reports. Defaults to the current job ID. No individual PR comments are posted.
    report-group: ""
```
